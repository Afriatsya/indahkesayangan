WEBSITE CINTA LENGKAP ❤️

1. Buka index.html.
2. Masukkan foto asli ke folder images:
   foto-utama.jpg
   foto-dia-1.jpg
   foto-dia-2.jpg
   foto-1.jpg sampai foto-6.jpg
3. Jika ingin musik, masukkan lagu MP3 milik/yang boleh digunakan ke:
   music/lagu-kita.mp3
4. Buka index.html di browser.

EDIT NAMA & ANNIVERSARY:
Buka index.html, cari:
const CONFIG={
  namaPacar:"Sayang",
  anniversary:"2027-09-27T00:00:00"
};

Ganti namaPacar dan tanggal anniversary sesuai kebutuhan.
